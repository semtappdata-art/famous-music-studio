## 🎯 SHOT TİPLERİ KODLAMASI

| Kod | Anlam | Kullanım |
|-----|-------|----------|
| **WS** | Wide Shot (Geniş Plan) | Mekan, ortam tanıtımı |
| **MS** | Medium Shot (Orta Plan) | Karakter üst yarısı |
| **CU** | Close Up (Yakın Plan) | Yüz, detay, el hareketi |
| **ECU** | Extreme Close Up (Çok Yakın) | Göz, dudak, parmak uçları |
| **OVER** | Over Shoulder (Omuz Üstü) | Diyalog, bakış açısı |
| **POV** | Point of View (Bakış Açısı) | Karakter perspektifi |
| **INSERT** | Insert (Ara Kesit) | Nesne, yazı, detay |
| **EST** | Establishing Shot (Tanım Planı) | Mekan giriş, zaman geçişi |
| **AERIAL** | Drone / Aerial (Hava) | Geniş manzara, giriş |
| **TIMELAPSE** | Zaman Geçişi | Güneş, bulut, trafik |
| **SLOWMO** | Yavaş Çekim (High FPS) | Dans, atlama, su, tüy |
| **WHIP** | Whip Pan (Hızlı Pan) | Geçiş, enerji artışı |
| **DOLLY** | Dolly In/Out | Yakınlaşma/uzaklaşma |
| **SLIDER** | Slider Lateral | Yatay kayma |
| **GIMBAL** | Gimbal / Steadicam | Takip, hareketli |
| **HANDHELD** | El Kamerası | Gerçekçilik, gerilim |
| **STATIC** | Sabit Kamera (Lock-off) | Kompozisyon, portre |
