# Ekipman Checklist — Çekim Günü (çıkışta işaretle)

## Kamera
- [ ] Ana kamera + dolu pil x3 (1 gece 4K ≈ 500GB-1TB yazar)
- [ ] Lens: f/1.8 ve altı (gece) + genel zoom
- [ ] Hafıza kartı: en az 1TB toplam + kart okuyucu
- [ ] Yedek gövde veya telefon (arıza yedeği)

## Hareket
- [ ] Gimbal (dengeli + kalibre) + yedek pili
- [ ] Tripod (timelapse için ŞART) + kumanda/intervalometre

## Işık
- [ ] Taşınabilir LED 5600K + difüzör + yedek pil
- [ ] Küçük pratik ışık (merdiven detayı için)

## Ses
- [ ] Harici kayıtçı (32-bit float) + yedek pil
- [ ] Ortam mikrofonu + rüzgar koruması

## İzleme + güç
- [ ] Monitörde 9:16 kılavuz çizgisi AÇIK (kontrol et!)
- [ ] Powerbank + çoklu priz + uzatma kablosu
- [ ] El feneri (ekip için) + ilk yardım mini seti

## Veri
- [ ] 2 adet taşınabilir SSD (gece sonu ÇİFT kopya)
- [ ] Kartlar dolmadan kopyalama planı (01:30 wrap'te)

## Evrak
- [ ] Mekan izin yazıları (çıktı/telefonda)
- [ ] Ekip iletişim listesi + acil durum numaraları
- [ ] Bu shot listesi (çıktı)
